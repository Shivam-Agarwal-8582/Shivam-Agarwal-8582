## 🚀 Featured Projects

### 🤖 AI Resume Analyzer
**Java · Spring Boot · Google Gemini API**

An AI-assisted application that compares resumes with job descriptions and provides actionable feedback.

- Integrates the Gemini API to generate resume feedback and recommendations.
- Supports ATS-oriented scoring, keyword analysis, and skill-gap insights.
- Uses prompt design to produce structured, relevant suggestions.
- Focuses on helping candidates identify ways to improve their resumes.

### ⚡ LRU Cache Visualizer
**HTML · CSS · JavaScript · Data Structures**

An interactive tool that demonstrates how a Least Recently Used cache works.

- Implements cache operations using a **HashMap and doubly linked list**.
- Demonstrates average **O(1)** lookup and update operations.
- Visualizes cache hits, misses, node movement, and eviction.
- Includes configurable capacity and operation history.

### 💺 Smart Seat Booking System
**HTML · CSS · JavaScript**

A responsive interface for selecting seats and managing a booking flow.

- Displays an interactive seating layout.
- Supports seat selection and booking validation.
- Updates the interface dynamically without a full page reload.
- Uses responsive styling for different screen sizes.

### ☁️ CloudVault — Cloud Storage Platform
**React · Spring Boot · AWS S3 · CloudFront · MySQL**

A cloud-storage application concept with a web interface and backend-managed file access.

- Explores S3-based storage and pre-signed URLs for controlled file access.
- Separates file metadata from stored file content.
- Uses a frontend/API/storage architecture.
- Explores static frontend hosting with CloudFront.
